# Instruções para o Lovable

Este projeto é uma captura estática da página **Exclusiva – Agência de Viagens**.

- `index.html` é o ponto de entrada (Vite serve direto).
- `styles.css` contém todos os estilos mesclados.
- `assets/images` e `assets/fonts` contêm as mídias.

## O que você pode pedir ao Lovable
- Converter este HTML/CSS estático em React + Tailwind.
- Recriar seções específicas como componentes.
- Ajustar cores, tipografia ou copy mantendo o layout.
