## Como usar no Lovable
1. Abra o Lovable e crie/abra um projeto.
2. Faça upload deste `.zip` — os arquivos já estão na raiz, prontos para importar.
3. Peça ao Lovable para converter em React ou editar as seções.

## Rodar localmente
```bash
npm install
npm run dev
```
